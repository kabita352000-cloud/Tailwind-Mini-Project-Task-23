# Greenwood Public Library Website

## About the Project

I created this Greenwood Public Library website using HTML and Tailwind CSS.


The website has different sections like the library collection, gallery, about section, events, membership, and contact information.

Add some simple hover effects and animations to make the website look better.

## Technologies Used

* HTML5
* Tailwind CSS
* Tailwind CSS CDN
* Responsive Design

## Features

### Navigation

* Library logo
* Navigation links
* Visit Us button
* Open Saturday badge
* Sticky navigation
* Mobile menu button
* Hover effect on navigation links

### Hero Section

* Main heading
* Short description
* Explore Collection button
* Join Free button
* Library image
* Library statistics
* Image hover effect

### Library Sections

The website has different library sections:

* Fiction
* Children's
* Science
* History
* Art & Design
* Digital

Each section has a title, description, and icon.

Added hover effects to the cards.

### Gallery

The gallery shows different areas of the library:

* Main Reading Room
* Study Lounge
* Archive Room
* Community Space

I used images and added simple hover zoom effects.

### About and Values

There is an About section where I added information about the library.

I also created a small grid for the library's values, such as:

* Community
* Events
* Digital Access
* Access for Everyone
* 40+ Years

### Responsive Design

I used Tailwind CSS responsive classes to make the website work on different screen sizes.

I checked the layout for desktop and smaller screens and adjusted the spacing and sizes where needed.

## What I Learned

While making this project, I learned how to use Tailwind CSS utility classes instead of writing a lot of normal CSS.

I practiced:

* Flexbox
* Grid
* Responsive classes
* Spacing
* Text sizes
* Colors
* Borders and rounded corners
* Hover effects
* Simple animations
* Creating responsive sections

## Challenges I Faced

One of the difficult parts was remembering which Tailwind classes to use for spacing, responsive design, and different layouts.

I also had to make some changes when the sections did not look good on smaller screens.

After checking the page and making changes, I understood Tailwind classes better.

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a browser.

Since I used Tailwind CSS CDN, I did not need to install Tailwind separately.

## Conclusion

This project helped me practice HTML and Tailwind CSS and understand how utility classes can be used to create a complete responsive webpage.
